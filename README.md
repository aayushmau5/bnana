# bnana

Personal app using Elixir & [Mob](https://mobframework.com/)

The iOS analytics widget is included by the normal physical-device build:

```sh
mix ios.native
```

On the first build, Xcode automatically creates Development provisioning profiles for `com.aayushmau5.bnana` and `com.aayushmau5.bnana.widget`, both with the `group.com.aayushmau5.bnana` App Group. Your Apple ID must be added in Xcode.
